# Proyecto Final – Gestión de Datos con SQL y NoSQL

## Descripción

Este proyecto implementa un sistema de gestión de datos utilizando dos paradigmas de bases de datos:

- **SQL Server** para el manejo de datos relacionales, con estructuras bien definidas y consultas estructuradas mediante SQL.
- **MongoDB** como base de datos NoSQL, ideal para almacenar documentos flexibles en formato JSON, permitiendo una integración más dinámica y escalable.

El objetivo principal es demostrar cómo ambos enfoques pueden coexistir en una solución técnica, aprovechando las fortalezas de cada uno según el tipo de información que se maneja.

## Tecnologías utilizadas

- SQL Server (Transact-SQL)
- MongoDB (NoSQL, BSON/JSON)
- Git para control de versiones
